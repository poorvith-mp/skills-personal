# Equipment-matched exercise substitutions

Use this to swap exercises based on stated equipment access, keeping the same movement pattern and trained muscle group.

| Movement pattern | Full gym | Home dumbbells | Bodyweight only |
|---|---|---|---|
| Horizontal push | Barbell bench press | DB bench/floor press | Push-ups (elevate feet for progression) |
| Vertical push | Overhead barbell press | DB shoulder press | Pike push-ups |
| Horizontal pull | Barbell/cable row | DB row | Inverted rows (table/sturdy bar) |
| Vertical pull | Lat pulldown / pull-up | Band-assisted pull-up | Pull-ups (if bar available) or towel rows |
| Squat pattern | Barbell back/front squat | Goblet squat | Bodyweight squat, Bulgarian split squat |
| Hinge pattern | Barbell deadlift/RDL | DB RDL | Single-leg RDL, glute bridge |
| Core/anti-rotation | Cable pallof press | DB pallof press (banded alt.) | Plank variations, dead bug |

**Progression principle across all equipment tiers:** once the current version becomes easy at the target rep range, progress by adding load (gym/dumbbells) or increasing difficulty of leverage/range of motion (bodyweight — e.g. standard push-up → decline push-up → archer push-up) rather than just adding more reps indefinitely.

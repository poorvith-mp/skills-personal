# What to Track: Personal Profile Categories

Categories of information to observe, capture, and maintain in user profile memory.

## 1. User Preferences & Working Style
- Language & tooling preferences (e.g., Python uv vs poetry, TypeScript strictness).
- Code formatting & architectural tastes (e.g., minimal dependencies, standard library first).
- Communication density (concise bullet points vs in-depth walkthroughs).

## 2. Project Context & Constraints
- Target audience, business objectives, and domain-specific terminology.
- Hard deadlines, deployment targets, and compliance requirements.

## 3. Feedback & Corrections
- Explicit corrections made during previous sessions.
- Anti-patterns to strictly avoid across all subsequent code generations.
